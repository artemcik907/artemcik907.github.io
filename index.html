Почему NoVir?

Принцип «Не навреди»

Автоматический бэкап реестра перед каждым опасным действием. NoVir никогда не трогает систему вслепую — сначала аудит, потом фикс.

6 языков интерфейса

Русский, Украинский, Английский, Немецкий, Польский, Французский. Переключение без перезапуска. Встроенный лог на выбранном языке.

Глубокая очистка сети

Удаляет вредоносные прокси-серверы из реестра, сбрасывает TCP/IP и DNS к заводским настройкам, восстанавливает оригинальный Hosts.

Полная прозрачность

Встроенный терминальный журнал записывает каждую выполненную команду. Вы всегда знаете, что именно сделала программа.

Осторожный подход

Диагностика старается не поднимать лишней паники: предупреждения показываются только при реальном наличии подозрительного значения. Но итоговое решение всегда остаётся за вами.

Асинхронная работа

Тяжёлые операции (бэкапы, сканирование, WMI-rebuild) выполняются в фоновых потоках — интерфейс не замораживается никогда.

Как работает NoVir

Программа работает в 4 этапа — от аудита до подтверждённого восстановления.

01

Аудит

NoVir читает состояние каждого из 12 проверяемых узлов. Никаких изменений — только сбор данных. Результаты отображаются в таблице с цветовыми статусами.

02

Отчёт

Каждая найденная проблема описывается: что обнаружено, почему это опасно, и какой именно фикс будет применён — вы знаете всё до нажатия кнопки.

03

Бэкап

Перед применением любого фикса программа автоматически создаёт снимок реестра. Этот шаг нельзя пропустить — безопасность встроена в архитектуру.

04

Фикс

Только выбранные вами исправления применяются точечно. После — повторный аудит того же узла для подтверждения результата.

Умная Диагностика MOD_01

Diagnostic Center — ядро NoVir. Программа проводит полный аудит системы и предоставляет вам список проблем с указанием причины и рекомендуемого фикса. Ничего не применяется автоматически без вашего ведома.

Сеть и Интернет
  • Файл Hosts: Ищет нестандартные записи, перенаправляющие трафик (фишинг, блокировка антивирусных сайтов).
    Фикс: удаление вредоносных строк, запись эталонного 127.0.0.1 localhost
  • DNS-серверы: Проверяет, не подменены ли DNS-адаптера. Вирусы часто ставят собственный DNS для перехвата запросов.
    Фикс: netsh dns flush + установка надёжных DNS или возврат к DHCP
  • TCP/IP стек: Детектирует повреждение сетевого стека.
    Фикс: netsh int ip reset + netsh winsock reset
  • Network Proxy (реестр): Ищет ключ ProxyEnable=1 в HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings, через который малварь перехватывает трафик браузера.
Критические узлы системы
  • Загрузчик BCD (testsigning): Проверяет через bcdedit /enum флаг тестового режима подписи — руткиты включают его для загрузки неподписанных драйверов.
  • Safe Mode (SafeBoot): Проверяет наличие ключей HKLM\SYSTEM\CurrentControlSet\Control\SafeBoot\Minimal. Их удаление вирусом делает вход в безопасный режим невозможным (BSOD).
  • Windows Defender: Проверяет статус Anti-Spyware, Real-Time Protection и наличие политик принудительного отключения защитника.
  • Системные Службы: Проверяет работоспособность wuauserv, BITS, Winmgmt, wscsvc.
  • WMI Repository: Проверяет целостность хранилища WMI. При повреждении многие системные инструменты перестают работать.
    Фикс: winmgmt /resetrepository
  • Windows Update / SoftwareDistribution: Ищет GPO-политики, блокирующие обновления, и раздутый кэш загрузок.
Критично: Safe Mode

Если ключи SafeBoot удалены вирусом — вход в безопасный режим вызовет BSOD. Примените фикс до перезагрузки!

Бэкап и Откат MOD_02

Менеджер безопасности работает по принципу «Не навреди». Любое действие программы обратимо — без исключений.

Автоматические бэкапы
  • Скрытый дамп реестра: Перед применением любого опасного фикса (сеть, BCD, WMI) NoVir в фоне экспортирует HKLM\SYSTEM и HKLM\SOFTWARE через reg export.
  • Асинхронный менеджер бэкапов: Отдельная вкладка для ручного создания точек восстановления. Процесс выполняется в фоновом потоке — интерфейс не замирает.
  • Хранение снимков: Все бэкапы сохраняются в папку NoVir\Backups\ рядом с программой с меткой даты и времени.
Умный откат (Rollback Manager)
  • Журнал изменений сессии: NoVir записывает каждый изменённый ключ реестра с исходным и новым значением.
  • Выборочная отмена: Таблица изменений позволяет отметить отдельные фиксы для отмены — не нужно откатывать всё сразу.
  • Восстановление из файла: Любой сохранённый .reg-дамп можно импортировать обратно через менеджер.

Рекомендуется создать ручной бэкап перед первым запуском NoVir на новой машине.

NoVir Explorer MOD_03

Независимый файловый менеджер — ваш последний рубеж, когда вирус заблокировал стандартный explorer.exe или скрывает свои файлы от стандартных инструментов Windows.

Возможности навигации
  • Полная независимость: Собственный движок обхода файловой системы — не зависит от состояния Explorer.
  • Мгновенный поиск: Фильтрация по подстроке имени файла в реальном времени.
  • Умные колонки: Сортировка по имени, размеру, дате изменения, типу файла.
  • Показ скрытых объектов: Переключатель «Скрытые файлы» — показывает элементы с атрибутами Hidden и System.
Операции с файлами
  • Контекстное меню: Удаление, переименование, открытие в стандартном менеджере — всё через правую кнопку мыши.
  • Принудительное удаление: Файлы удаляются напрямую через WinAPI в обход стандартных проверок оболочки Windows.
  • Открытие с повышенными правами: Запуск выбранного файла от администратора.

Утилиты Фикса MOD_04

Набор точечных инструментов для снятия вирусных блокировок интерфейса. Каждый инструмент действует хирургически на конкретный параметр реестра или системный компонент.

Разблокировка интерфейса
  • Разблокировка Regedit: Удаляет DisableRegistryTools=1 из HKCU и HKLM — возвращает доступ к редактору реестра.
  • Разблокировка Диспетчера задач: Удаляет DisableTaskMgr=1 — позволяет завершать вирусные процессы.
  • Разблокировка CMD: Удаляет политику DisableCMD, которую вирусы ставят для блокировки командной строки.
Восстановление системы
  • Ассоциации файлов: Восстанавливает стандартные обработчики для .exe, .bat, .cmd, .com — файлы снова запускаются двойным кликом.
  • Фикс Рабочего Стола: Очищает IconCache.db, восстанавливает ключ lnkfile и безопасно перезапускает explorer.exe.
  • Восстановление UAC: Сбрасывает политику EnableLUA к стандартному значению — возвращает контроль учётных записей.
  • Очистка автозапуска: Сканирует Run, RunOnce, Winlogon на посторонние записи и позволяет выборочно удалить их.
Внимание

Перед применением фиксов рекомендуется создать бэкап реестра через вкладку «Бэкап и Откат».

Лог и Языки MOD_05

NoVir предоставляет полную прозрачность работы через встроенный журнал и поддерживает 6 языков интерфейса.

Терминальный журнал
  • Запись всех действий: Каждая выполненная команда логируется с меткой времени: фиксы, бэкапы, результаты диагностики.
  • Цветовая маркировка: Успех (✓ OK), предупреждение (! WARNING), ошибка (✕ ERROR), информация (i INFO).
  • Сохранение лога: Экспорт журнала в .txt-файл для отправки разработчику или архивирования.
  • Очистка: Кнопка очистки журнала без перезапуска программы.
